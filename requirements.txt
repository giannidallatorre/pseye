# Python dependencies for the PS3 Eye -> webcam bridge.
#
# pseyepy is not on PyPI in a usable form for macOS: install it from git.
# It vendors PS3EYEDriver (the C driver) and builds it against libusb.
#
# h5py is not declared by pseyepy but is required: pseyepy/__init__.py imports
# pseyepy.io, which imports h5py at module level. Without it, `import pseyepy`
# fails with ModuleNotFoundError.
#
#   brew install libusb
#   python3 -m venv .venv
#   .venv/bin/pip install -r requirements.txt
#
